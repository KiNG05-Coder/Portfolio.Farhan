## Progression

ARGUS-6 is developed in order — each stage has to work before the next one is
meaningful.

| Stage | Status |
| --- | --- |
| Communication | Working |
| Low-level control | Working |
| Inverse kinematics | Working |
| Gait | Working |
| Manual motion | Working |
| Sensors | In development |
| AI | Planned |
| Navigation | Planned |
| Autonomy | Planned |
| Field testing | Planned |

## Evidence

This is where measured results will go as they are produced:

- Locomotion test video
- Arm & gripper test video
- YOLO benchmark on the actual Raspberry Pi 4
- Bench and assembly photos
- Representative run logs

No test results are published until they have actually been recorded on the
robot.
